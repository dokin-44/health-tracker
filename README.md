# 헬스 루틴 기록

운동 종목, 무게, 횟수, 세트를 기록하고 종목별 기록과 주간 요약을 확인하는 프로그램입니다.
같은 주제를 두 가지 방식으로 만들었습니다.

| 버전 | 언어 | 실행 방법 | 기록 저장 위치 |
|---|---|---|---|
| 콘솔 버전 | Python | 터미널에서 `python main.py` | `records.json` 파일 |
| 웹 버전 | HTML, CSS, JavaScript | 브라우저에서 `docs/index.html` 열기 | 브라우저 localStorage |

웹 버전 주소: https://dokin-44.github.io/health-tracker/

## 웹 버전

서버나 설치 없이 정적 파일만으로 동작합니다. `docs` 폴더의 `index.html`을 브라우저로 열면 바로 사용할 수 있고,
GitHub Pages로도 배포되어 있습니다. 화면 아래의 탭으로 홈, 기록, 종목별, 주간 페이지를 오갑니다.

### 기능

| 페이지 | 기능 |
|---|---|
| 홈 | 오늘 기록 요약, 이번 주 목표 진행률, 연속 운동일, 이번 달 운동일 달력, 최근 기록, 예시 데이터 넣기와 전체 초기화 |
| 기록 입력 | 종목, 무게, 횟수, 세트 저장, 오늘 입력한 기록 목록과 삭제, 최근 종목 빠른 입력, 신기록 알림, 기록 백업(내보내기와 가져오기) |
| 종목별 조회 | 종목별 전체 기록, 최고 무게, 예상 1RM, 무게 추이 그래프, 종목별 최고 기록 한눈에 보기 |
| 주간 요약 | 월요일부터 일요일까지의 운동한 날, 총 세트, 총 볼륨, 이전 주와 다음 주 이동, 주간 목표 설정, 지난주 대비 증감 |

- 예상 1RM은 Epley 공식(무게 x (1 + 횟수 / 30))으로 계산한 추정치이며 실제 측정값이 아닙니다.
- 신기록 알림은 같은 종목의 이전 기록보다 최고 무게나 예상 1RM이 높을 때 나타납니다. 처음 하는 종목은 첫 기록이라고 안내합니다.
- 총 볼륨은 무게 x 횟수 x 세트를 합한 값입니다.

### 기록 저장과 백업

- 기록은 사용하는 브라우저의 localStorage에 저장됩니다(`records`, 주간 목표는 `weeklyGoalSets`).
- 같은 주소를 다른 기기나 다른 브라우저로 열면 기록이 보이지 않습니다. 브라우저의 사이트 데이터를 지우면 기록도 함께 지워집니다.
- 기록 입력 페이지의 `내보내기`로 JSON 파일을 받고, `가져오기`로 다른 브라우저에서 다시 불러올 수 있습니다. 완전히 같은 기록은 건너뜁니다.
- 콘솔 버전의 `records.json`도 같은 형식이라 웹 버전의 `가져오기`로 불러올 수 있습니다.

## 콘솔 버전

- Windows: `python main.py`
- macOS / Linux: `python3 main.py`

메인 메뉴에서 번호를 선택합니다.

| 번호 | 메뉴 | 설명 |
|---|---|---|
| 1 | 기록 추가 | 종목, 무게, 횟수, 세트를 입력하면 오늘 날짜로 `records.json`에 자동 저장 |
| 2 | 기록 보기 | 기록이 있는 날짜가 최신순으로 표시되고, 번호를 입력하면 그 날짜의 기록만 표시 (`0`은 메인 메뉴로) |
| 3 | 종목별 조회 | 종목 이름으로 기록을 조회하고 최고 무게 기록을 표시 |
| 4 | 주간 요약 | 이번 주 월요일부터 일요일까지의 운동한 날짜 수, 총 세트 수, 총 반복 횟수, 종목별 세트와 반복 횟수 |

- 프로그램을 다시 실행해도 `records.json`에 저장된 이전 기록을 볼 수 있습니다.
- 개인 운동 기록 파일(`records.json`)은 Git에 포함되지 않습니다.
- 주간 요약 테스트: `python test_weekly_summary.py`

### 두 버전의 차이

- 콘솔 버전의 주간 요약은 총 반복 횟수를, 웹 버전은 총 볼륨(무게 x 횟수 x 세트)을 보여 줍니다.
- 콘솔 버전의 기록은 `records.json`, 웹 버전의 기록은 브라우저에 따로 저장되며 자동으로 동기화되지 않습니다.

```
docs/                   웹 버전 (GitHub Pages 배포 폴더)
  index.html            홈
  add.html              기록 입력
  by-exercise.html      종목별 조회
  weekly.html           주간 요약
  storage.js            기록 저장과 공통 함수
  nav.js                하단 탭 메뉴
  style.css             공통 스타일
CONTRIBUTING.md         작업 방법과 담당
```
