## 운동 기록 저장
- Windows: `python main.py`
- macOS / Linux: `python3 main.py`

`python3 main.py`로 실행한 후 `1. 기록 추가`에서 종목, 무게, 횟수, 세트를 입력합니다.
입력한 기록은 `main.py`와 같은 폴더의 `records.json`에 자동 저장됩니다.
프로그램을 다시 실행해도 `2. 기록 보기`에서 이전 기록을 확인할 수 있습니다.
기록 보기를 선택하면 기록이 있는 날짜가 최신순으로 번호와 함께 표시됩니다. 날짜에 해당하는 번호를 입력하면 해당 날짜의 운동 기록만 표시됩니다. `0`을 입력하면 메인 메뉴로 돌아갑니다.
개인 운동 기록 파일은 Git에 포함되지 않습니다.


## 주간 운동 요약

메인 메뉴에서 `4. 주간 요약`을 선택하면 이번 주 월요일부터 일요일까지의 운동 기록을 요약해서 확인할 수 있습니다.

다음 항목을 확인할 수 있습니다.

- 운동한 날짜 수
- 총 운동 세트 수
- 총 반복 횟수
- 종목별 세트 수와 반복 횟수

이번 주 운동 기록이 없는 경우 기록이 없다는 안내 메시지가 출력됩니다.
